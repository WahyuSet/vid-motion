# demo-cicak — sources

Short engine demo (sticker, x-ray, cutaway, data card + scramble, pill captions); not an idea in `ideas.md`.

- **Token listrik prabayar adalah kode 20 angka yang terenkripsi khusus untuk satu meteran.** Standard Transfer
  Specification (STS), IEC 62055-41: a token is a 20-digit number made by encrypting the transfer (amount, token
  identifier) with the decoder key of one specific meter; another meter cannot decrypt it.
  STS Association (https://www.sts.org.za/), standard IEC 62055-41. Check the URL before using this claim in a real video.
